# 3d-mahjong

## Development shortcuts

- `game/gamedb/gamedb.tscn`: configure the challenge timer, challenge level IDs, and active levels JSON.
- `game/scenes/level_editor/level_editor.tscn`: run this scene to edit `data/levels.json`.
- `game/bytebrew/bytebrew_web.gd`: set `ENABLED` to control ByteBrew initialization in web builds.
